    🚀 BOOSE Project

    A robust Graphical Command Interpreter built in C#


    Get Started   •   API Reference   •   View on GitHub


    ⚡ What is BOOSE?

    BOOSE is a C# library designed to parse and execute graphical commands. It features a robust Canvas system, command factory, and variable handling, allowing users to draw shapes and perform logic programmatically.

    ✨ Key Features

    🎨 Canvas Drawing 🔧 Command Logic 💾 Variable Storage
    Draw circles, rectangles, and lines with ease using the AppCanvas implementation. Includes support for If, Else, While, and For loops for complex drawing algorithms. A full variable system (AppVariable) allows you to store and manipulate data at runtime.

    👩‍💻 Quick Code Example

    Here is how simple it is to draw a circle using the BOOSE syntax:

    // Initialize the factory and parser
CommandFactory factory = new AppCommandFactory();
Parser parser = new Parser(factory, new StoredProgram(myCanvas));

// Execute a command
parser.ParseCommand("circle 50");
