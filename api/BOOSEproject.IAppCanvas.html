    Class IAppCanvas

    Application canvas implementation used by the program for all drawing operations. Implements the BOOSE.ICanvas interface expected by command objects.

    Remarks

    This class wraps a Bitmap and Graphics instance to draw shapes and text. It stores the current pen/cursor position in Xpos and Ypos.
