    ParseCommand(string)

    Parses a single line of BOOSE code into an BOOSE.ICommand.

    A single line of source code. A compiled BOOSE.ICommand instance representing the line, or null when the line is a comment (lines starting with *). Thrown when the command token is unknown or empty and no matching command can be created. This method:
    1. Skips comment lines.
    2. Tidies operators so tokenization can be done on whitespace.
    3. Extracts the leading command token and preserves the remaining text as parameters.
    4. Applies assignment rewriting so plain x = 5 is treated as an int evaluation.
    5. Uses the configured BOOSE.ICommandFactory to instantiate and compile the command.
